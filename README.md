# Portfolio Website

A personal portfolio built with **React** and **Tailwind CSS**, designed to showcase my skills, projects, and contact details in a clean and structured way.

## Why These Choices
- **React**: Chosen for its **reusability** and **component-based approach**, allowing better structure and scalability.  
- **Tailwind CSS**: Used for **faster and easier styling**, enabling a responsive and consistent UI with minimal custom CSS.  

## Components Added
- **Navbar.jsx** – Handles navigation across all pages using React Router.  
- **Profile.jsx** – Displays personal details, skills, and education.  
- **Portfolio.jsx** – Overall portfolio layout and structure.  
- **Project.jsx** – Showcases projects with details, including the FS Practical.  
- **Blogs.jsx** – Placeholder for upcoming blog content.  
- **Contact.jsx** – Shows email, LinkedIn, and GitHub information.  

## Concepts Applied
- **React Router** – For smooth navigation between Home, Projects, Blog, and Contact pages.  
- **useState Hook** – For managing dynamic UI states.  
- **Component Reusability** – Components like Navbar are reused across multiple pages.  
- **File Structure** – Organized into:
  - `components/` – Reusable UI components  
  - `data/` – Data-driven content  
  - `assets/` – Images and static files  

## Features
- **Home**: Personal details, skills, and education.  
- **Projects**: List of projects including the FS Practical.  
- **Blog**: Coming soon.  
- **Contact**: Email, LinkedIn, and GitHub links.  

## Tech Stack
- React  
- Tailwind CSS  
- React Router
